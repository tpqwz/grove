Snippet

Space means AND. OR and NOT are capitals. Quotes are a phrase. A trailing * is a prefix, and ~ is one edit. Stemming matches inflections. Fuzzy allows one edit on longer words. Concepts adds related words and marks them in blue. Snippet is the sentence, a few sentences nearby, or the passage.

Add a folder, a file, or a web page. Each volume is a Dublin Core record. The shelf groups by creator. A file named Title — Author shows that author until the record has one. Sort any column. Identifier and the rest of the record stay in Edit, and that record is kept in the index. The text stays on disk.

One person, however many names the books use. Author is the creator. A contributor written as Role: Name takes that role, such as Translator, Editor, or Speaker. A source that begins Translated by, Edited by, or Read by counts as that role. Opening a name fetches a short public profile, and a photograph when one is public. Both are kept in the index.

Select a passage in a book and choose Save excerpt. The collection keeps the wording, the place, and a citation in the index. The book stays in the library.

Copy all, Text, and JSON include the whole collection.

These choices are kept for this window. A search uses them at once.
